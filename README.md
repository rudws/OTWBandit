Learning Linux the Hard Way: My OverTheWire Bandit Journey

This repository documents my first steps into Linux and the command line, working through the OverTheWire Bandit wargame. Bandit teaches basic Linux skills through small puzzles. Each level hides the password for the next one somewhere you have to find it, decode it, or get the right program to reveal it.

I worked through these in a Kali Linux virtual machine. The notes here are my own findings from each level, which I tidied up with Claude’s help.

Why I Did This

I had never used a Linux terminal before. I wanted to understand how servers, permissions and networking actually work, and Bandit gave me a safe, legal place to practise without breaking anything real.
